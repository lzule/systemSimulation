## 1. 系统概况

| 维度 | 内容 |
|------|------|
| 架构 | 四实体闭环：Target → Gimbal → Camera → Raspi，由 DigitalTwinRuntime 按 tick 调度 |
| 时钟 | dt=5ms，200Hz 统一 tick |
| 配置 | 11 个 dataclass 集中在 config.py，以模块级单例实例提供 |
| 测试 | 224 单元测试 + 16 集成测试（含 8 个 e2e 闭环基线测试），共 240 测试用例，全部通过 |
| 运行方式 | GUI 实时模式 / 无 GUI 离线模式 |
| 延时仿真 | Raspi 单槽忙/闲延时管线（IDLE → READING → PROCESSING → SENDING → IDLE），可配置 |

## 2. 已具备能力

### 2.1 目标模型（Target）

- **运动模型**：`TargetKinematics2D`，纯 2D 平面（x, y），无 z 坐标
- **运动模式**：5 种 — sinusoidal / constant_velocity / constant_accel / random_walk / waypoint
- **状态输出**：x_m, y_m, vx_mps, vy_mps, bearing_deg, distance_m
- **参数管理**：全部集中在 `TargetConfig` dataclass + `MOTION_MODE_PARAMS` 注册表
- **随机可控**：random_walk 模式有独立 seed，不影响全局随机状态

### 2.2 云台模型（Gimbal）

- **双轴控制**：`CascadedController2Axis`，yaw/pitch 独立串级 PID
  - 外环 P（角度环）50Hz：angle_kp=14.0
  - 内环 PI（速率环）200Hz：rate_kp=1.6, rate_ki=5.0
- **被控对象**：一阶惯性环节（tau=30ms）
- **角度限位**：yaw ±90°，pitch [-135°, +90°]
- **速率限幅**：60 deg/s
- **工作模式**：ANGLE_MODE（角度跟踪）/ RATE_MODE（速率跟踪）
- **状态机**：OFF → BOOTING → READY（boot delay 1.5s）

### 2.3 相机模型（Camera）

- **成像模型**：针孔投影 + 高斯亮点渲染
  - 分辨率 640×480，sensor 4.8×3.6mm，焦距 12mm
  - f_px=1600，FOV≈21.2°，px_per_deg≈27.9
- **目标成像**：beacon_sigma=3.2px 高斯亮点
- **像素噪声**：高斯噪声 std=2.0px
- **检测算法**：阈值（threshold=180）+ 质心定位（`detect_beacon_centroid`）
- **变焦控制**：4.4mm ~ 200mm 连续变焦，指数逼近
- **关键限制**：`v = h / 2.0` 硬编码（model.py），目标始终在图像垂直中心，实质为 1 轴闭环

### 2.4 树莓派模型（Raspi）

- **延时管线**：单槽忙/闲状态机（IDLE → READING → PROCESSING → SENDING → IDLE）
  - 忙时不接受新帧，空闲时取最新帧，不积压
- **延时参数**：image_read 5ms + image_process 15ms + state_read 3ms + command_tx 3ms（默认无延时时全部为 0）
- **jitter**：`abs(gauss(0, std))`（已修正正偏 bug）
- **控制程序协议**：`on_tick(obs) -> list[Command]`，可插拔
- **观测输入**：obs 含 timestamp, target（含真值）, gimbal, camera, frame

### 2.5 基线跟踪器（BaselineTrackerProgram）

- **控制律**：P 控制器，`yaw_rate = Kp × (u - cx)`
- **参数**：Kp=1.1 dps/px, max_rate=60 dps, deadband=2px
- **限制**：pitch_rate 恒为 0，仅 yaw 单轴闭环
- **未使用真值**：仅依赖 frame 中的 u 坐标和 cx，未读取 target 真值

### 2.6 运行时与工具链

| 工具 | 功能 |
|------|------|
| `app.py` | 主入口，透传到 simulation.cli |
| `tools/pid_tuner.py` | PID 参数对比，输出 RMS / track_ratio / settle_s |
| `tools/tune_tracker_kp.py` | Kp 自动扫参，输出 angle_rms / pixel_rms 排序表 |
| `tools/step_response.py` | 阶跃响应分析，输出 rise_ms / settle_ms / overshoot / ss_error |
| `tools/record_session.py` | 录制仿真数据到 CSV |
| `tools/replay_session.py` | 回放 CSV 数据 |
| `tools/target_preview.py` | 2D 轨迹预览 |
| `tools/camera_3d_viewer.py` | 3D 针孔投影可视化 |
| `tools/config_editor.py` | GUI 参数编辑器 |

## 3. 当前限制

| # | 限制 | 来源 |
|---|------|------|
| 1 | 目标为纯 2D 模型（x, y），无 z 坐标/高度/俯仰 | TargetKinematics2D |
| 2 | 视觉闭环实质 1 轴（yaw only），v = h/2.0 硬编码，pitch_rate = 0 | camera/model.py, tracker_program.py |
| 3 | 图像过于理想：黑底 + 单高斯亮点 + 阈值质心，无泛化能力 | camera/model.py |
| 4 | 无 ATP 概念：无捕获/粗跟踪/精跟踪/失锁恢复状态机 | 代码中无相关实现 |
| 5 | 无统一坐标系定义，隐式约定 bearing = atan2(y, x) | 无坐标系文档 |
| 6 | 观测泄漏：控制程序可访问全部 target/gimbal/camera 真值 | obs 字典含完整真值 |
| 7 | 无通信链路仿真 | 未实现 |
| 8 | 检测算法不具鲁棒性（固定阈值 + 质心） | detect_beacon_centroid |
| 9 | 端到端评价体系仍不完整（已有基线 e2e 测试，但缺多场景覆盖） | tests/test_e2e_baseline.py |
| 10 | 单目标，无多目标/遮挡 | 架构限制 |
