# 研究基线配置（Phase 0 冻结）

> 冻结时间：2026-05-14
> 基于：config.py 中 11 个 dataclass 的默认值
> 用途：后续所有实验默认引用本配置，修改参数时必须注明偏离项

---

## 1. 目标参数（TargetConfig）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| motion_type | sinusoidal | 正弦运动 |
| initial_x_m | 100.0 | 初始 x 位置 |
| initial_y_m | 0.0 | 初始 y 位置 |
| velocity_x_mps | 0.0 | x 方向速度 |
| velocity_y_mps | 1.5 | y 方向速度 |
| accel_x_mps2 | 0.0 | x 方向加速度 |
| accel_y_mps2 | 0.3 | y 方向加速度 |
| sin_amplitude_m | 15.0 | 正弦振幅 |
| sin_frequency_hz | 0.2 | 正弦频率 |
| random_max_accel_mps2 | 1.0 | 随机运动最大加速度 |
| random_damping | 0.98 | 随机运动阻尼 |
| random_seed | 42 | 随机运动种子 |
| waypoint_arrival_radius_m | 1.0 | 航点到达半径 |

**基线运动参数推导**：
- 目标在 x=100m 处做正弦振荡，振幅 15m，周期 5s
- 最大线速度 = 2π × 15 × 0.2 = 18.85 m/s
- 最大角速率 ≈ 18.85 / 100 × (180/π) ≈ 10.8 deg/s

## 8. 树莓派参数（RaspiConfig + RaspiDelayConfig）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| boot_delay_s | 1.0 | 上电启动延时 |
| image_read_delay_s | 0.005 | 图像读取延时 |
| image_process_delay_s | 0.015 | 图像处理延时 |
